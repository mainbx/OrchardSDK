## Extension strategy

OrchardSDK keeps communication, approvals, policies, and audit semantics in core. External systems (email, ticketing, chat platforms) should be implemented as adapters.

## Current extension set

- Email integration stubs for Gmail, Outlook, ProtonMail, and Yahoo Mail.

See the Email Integrations page for implementation details and limitations.
